# -arene-des-algos-HOUDAOUADAH
## Objectif

Construire un pipeline complet de Machine Learning et comparer plusieurs
algorithmes de classification.

## Contenu du projet

- exploration des données ;
- séparation entre données d'entraînement et données de test ;
- entraînement de plusieurs modèles ;
- comparaison des accuracies ;
- clustering non supervisé ;
- visualisations ;
- matrices de confusion ;
- mise à l'échelle des données ;
- démonstration d'une fuite de données ;
- sélection et justification d'un modèle champion.
